#  Cara ou Coroa

Um simples jogo de **cara ou coroa** feito em HTML, CSS e JavaScript.  
O jogador clica no botão e a moeda gira, mostrando aleatoriamente **cara** ou **coroa**.

---

##  Como jogar
1. Abra o site publicado no GitHub Pages:  
    [Clique aqui para jogar](https://oliver06z.github.io/cara-e-coroa/)
2. Clique no botão **Jogar Moeda**.
3. Veja o resultado: **Cara** ou **Coroa** 

---

##  Estrutura do projeto
caraecoroa-html/
├── index.html      # Página principal
├── style.css       # Estilos do jogo
├── script.js       # Lógica da moeda
└── imagem/
├── cara.png   # Lado da cara da moeda
└── coroa.png  # Lado da coroa da moeda

---

## 🛠️ Tecnologias usadas
- **HTML5** → estrutura da página  
- **CSS3** → estilização e animações  
- **JavaScript** → lógica do sorteio da moeda
